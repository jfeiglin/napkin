# Briefs S1-F and S1-E: templates, tables and collections

Read `briefs/COMMON-B.md` first, then the brief of the same track of S0 (`s0-front.md` or
`s0-engine.md`): the ownership and the rules of S0 hold, except where this file says otherwise.
State files: `scratch/rewrite/b1/s1-front/STATE.md` and `scratch/rewrite/b1/s1-engine/STATE.md`.

## Where S0 left things

`napkin run` compiles and runs a model of entities declared once, with inputs, stores, formulas
and directed flows (`examples/piano_tuners`). The front end refuses the constructs of later slices
with the code `later_slice`; the engine refuses them with `Outside`, naming the slice. The program
(`napkin/program/`) already describes the whole language, and `tests/program/examples.py` holds 65
examples that the oracle (`tests/reference/`) runs. Read `scratch/rewrite/b1/s0-*/STATE.md`.

## The subset of S1

Templates (a declaration with fields that several instances share), instances written by hand,
links to other entities (`origin: Place`), `this` and paths through links (`this.origin.level`),
tables (`sites: Place from "places.csv"`) with typed columns, an `id` column that names each row
(`sites.clinic`) and link cells that name rows of another table, `Template.instances`, collection
literals (`<this.primary, this.backup>`), projection (`routes.limit`), the reductions `sum`,
`count`, `any`, `all`, `min` and `max`, `where` on fixed fields, `by(field)`, `.at(x)` with its
key times, `assert` over inputs, and initializers that follow their dependencies across members.
Flows between members of different templates, sharing at an endpoint and everything later stay
refused (S2 and after).

## S1-E: the engine

You own what S0-E owned. Run the subset above:
- **Pools of members**: each template's members as rows, links as columns of row numbers, a reverse
  index for `where(link == this)`, a sorted index of keys for `.at(x)`, whose key times go on the
  timeline (`Reading.instances.by(hour).at(t)` changes at each key time and holds after the last).
- **Reductions** that follow their members: `sum` by the pairwise trees of `timeline/trees.py`,
  `count`, `any`, `all`, `min`, `max`; `min` and `max` of an empty collection fail (D4).
- **Scale**: a large family of like rows runs on arrays, not as one component per row; the layout of
  `scratch/rewrite/a4a/layout.py` ran 30,000 places to 48 h in 1.4 s. Once, at the end, run a model of
  30,000 rows that reads keyed and reduced values, and give its time in your last message (a
  benchmark, not a test).
- **Tests**: the examples of the subset, against their expected results and the oracle; a reordered
  table gives the same named results; port the engine tests of slice S1 in the triage that the
  subset covers (such as `test_timeline_long_steps.py` and `test_timeline_bounds.py`); list each.
